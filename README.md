# 📁 Dosya Gezgini - ASP.NET MVC Projesi

Bu proje, ASP.NET MVC framework'ü kullanılarak geliştirilen bir **Dosya Yönetim ve Gezgini** uygulamasıdır. Kullanıcıların dosya ve klasörleri yükleyebileceği, görüntüleyebileceği, silebileceği, geri yükleyebileceği bir sistem sunar. Ayrıca yetkilendirme sistemi sayesinde kullanıcı bazlı dosya erişimi sağlanır.

---

## 🚀 Özellikler

- ✅ Klasör ve dosya oluşturma
- ✅ Dosya yükleme / silme / geri yükleme
- ✅ Silinen dosyalar için "Çöp Kutusu" yönetimi
- ✅ Kullanıcı bazlı oturum yönetimi (Login / Register)
- ✅ Yetki bazlı görünürlük (Admin / Kullanıcı)
- ✅ Bootstrap + FontAwesome ile şık arayüz
- ✅ Entity Framework Core ile SQL veri tabanı yönetimi

---

## 🛠️ Kullanılan Teknolojiler

- ASP.NET Core MVC
- Entity Framework Core
- MS SQL Server
- Bootstrap 5
- FontAwesome
- LINQ
- Identity (isteğe bağlı)
